## 🔴 2026-11-03 回退记录

**阶段 0-1 验证结果**：
- 阶段 0.1（插件内操作会话）：✅ 通过（session.append 可用）
- 阶段 0.2（插件内连 OneBot）：✅ 通过（WS 需用 OneBot 配置里的独立 token）
- **阶段 1 核心（投递→kick→处理）：❌ 未通过**
  - `sessions.create` 返回的 agent 与 `sessions.get` 的 session 不是同一对象
  - inbox 投影为 null，投递事件未生效
  - kick 后会话消息 0 条

**结论**：DSH 的 agent/session/投影机制比预期复杂，需要源码级理解；继续成本不可控。

**决定**：回退到现有架构（web + 桥接）。fish 插件保留已完成部分（memory/发送）。

**恢复**：bridge 测试组件已从 apply 移除；桥接已恢复，小鱼在线。

**以后要继续**：另开独立测试 profile 验证投递机制，不挂主 profile。
